Removing Ads From the Gallery App

Fleeting

tl;dr: ça ne s’installe pas

The gallery app (gallery.photomanager.picturegalleryapp.imagegallery) version 6.0.7 shows interstitial ads (AppLovin MAX mediation with AdMob + Chartboost) every time you press the back button in photo or video viewing activities.

The ad logic lives in a single static method YYyyyyvvvv.Yyyyyyyyyyyyyyyyyyyyyyyyyyyyy() that returns true when ads should be shown. By patching it to always return false, all ad triggers are neutralized.

We also rename the package so it can be installed side by side with the original.

download and extract the XAPK

rm -rf gallery-disassembled gallery-noads.apk
curl -L -o gallery.xapk "https://d.apkpure.net/b/XAPK/gallery.photomanager.picturegalleryapp.imagegallery?versionCode=288&nc=arm64-v8a&sv=23"

extract the base APK and split APKs from XAPK

unzip -o gallery.xapk \
  gallery.photomanager.picturegalleryapp.imagegallery.apk \
  config.arm64_v8a.apk \
  config.en.apk \
  config.mdpi.apk

disassemble the base APK with apktool

apktool d gallery.photomanager.picturegalleryapp.imagegallery.apk -o gallery-disassembled

merge the arm64 native libraries into the disassembled project

The split APK config.arm64_v8a.apk contains native .so files needed at runtime. We merge them into the base so we get a single standalone APK.

mkdir -p /tmp/split_arm64
unzip -o config.arm64_v8a.apk -d /tmp/split_arm64
mkdir -p gallery-disassembled/lib/arm64-v8a
cp /tmp/split_arm64/lib/arm64-v8a/*.so gallery-disassembled/lib/arm64-v8a/
ls -lh gallery-disassembled/lib/arm64-v8a/

patch the ad enable check to always return false

The method YYyyyyvvvv.Yyyyyyyyyyyyyyyyyyyyyyyyyyyyy()Z is the single gate that controls whether ads are shown. It checks:

  1. upgrade_user preference (premium purchased)
  2. show_ads preference
  3. ad click rate limiting

Both PhotosViewActivity and VideoPlayerActivity call this method on back press. If it returns true and the AppLovin SDK is initialized, an interstitial ad is shown instead of navigating back.

We replace the method body to always return 0 (false), so the ad code path is never taken and back navigation works normally.

  cat > /tmp/patch_ads.py << 'PYEOF'
import re

filepath = "gallery-disassembled/smali_classes4/YYyyyyvvvv.smali"
with open(filepath, "r") as f:
    content = f.read()

old_method = re.search(
    r'(\.method public static Yyyyyyyyyyyyyyyyyyyyyyyyyyyyy\(\)Z\n)'
    r'(.*?)'
    r'(\.end method)',
    content,
    re.DOTALL
).group(0)

new_method = """.method public static Yyyyyyyyyyyyyyyyyyyyyyyyyyyyy()Z
    .locals 1

    const/4 v0, 0x0

    return v0
.end method"""

content = content.replace(old_method, new_method)

with open(filepath, "w") as f:
    f.write(content)

print("Patched ad enable check to always return false")
PYEOF
  python3 /tmp/patch_ads.py

rename the package for side-by-side installation

Change the package name and all provider authorities in the manifest so that it does not conflict with the original app.

sed -i \
  's/gallery\.photomanager\.picturegalleryapp\.imagegallery\b/gallery.photomanager.picturegalleryapp.imagegallery.noads/g' \
  gallery-disassembled/AndroidManifest.xml
echo "Package renamed to gallery.photomanager.picturegalleryapp.imagegallery.noads"

remove the requiredSplitTypes attribute

Since we merged everything into a single APK, the split requirement must be removed or Android will refuse to install it.

sed -i \
  's/ android:requiredSplitTypes="[^"]*" android:splitTypes="[^"]*"//' \
  gallery-disassembled/AndroidManifest.xml
echo "Removed requiredSplitTypes"

reassemble the APK

apktool b gallery-disassembled -o gallery-noads.apk

create a signing keystore

rm -f debug.keystore
keytool -genkey -v \
  -keystore debug.keystore \
  -storepass android \
  -alias androiddebugkey \
  -keypass android \
  -keyalg RSA \
  -keysize 2048 \
  -validity 10000 \
  -dname "CN=Debug, OU=Debug, O=Debug, L=Debug, ST=Debug, C=US"

sign the APK

apksigner sign \
  --ks debug.keystore \
  --ks-pass pass:android \
  --key-pass pass:android \
  --ks-key-alias androiddebugkey \
  gallery-noads.apk
ls -lh gallery-noads.apk

install on the phone

Since the package has been renamed, it can be installed alongside the original. You need to uninstall any previous version with the .noads package name first if upgrading.

adb install gallery-noads.apk

cleanup

rm -f gallery.xapk \
  gallery.photomanager.picturegalleryapp.imagegallery.apk \
  config.arm64_v8a.apk config.en.apk config.mdpi.apk
echo "Cleaned up temporary files"
