New Cap for a Flask

Fleeting

It’s basically:

  1. a half sphere halo
  2. with a small cap at one side
  3. and a clip at the other side

sphere + cap

The design I choose is to model the main half spherical body with the small cap as a sphere and a cylinder that I cut in half.

So first, the sphere with cap part.



sphere_workplane = cq.Workplane("XY", origin=(0, 0, -cap_height))

sphere_cap = (
    sphere_workplane.sphere(sphere_radius)
    # with offset cylinder to make the cap
    .composeunion(
        cq.Workplane("XY", origin=(cap_length,0,0)).cylinder(cap_height*2, sphere_radius)
    )
)

Then, I cut it in half.



cap_plain = (
    sphere_cap
    # keep only half of it
    .composecut(
        cq.Workplane("XY")
        .box(20*sphere_radius, 20*sphere_radius, 20*sphere_radius, centered=(True, True, False))
    )
)

Then, I can simply “dig” the cavity inside it, like this.



cavity = sphere_workplane.sphere(sphere_radius-wall_width)

with_cavity = cap_plain.composecut(cavity)

add the attach

Now, let’s design that small cylindric part to stick with the flask.

I start with a simple cylinder, at the correct position.



attach_worplane = cq.Workplane("XZ", origin=(- sphere_radius-cylinder_radius, 0, 0))

attach = (
    attach_worplane
    .cylinder(cylinder_height, cylinder_radius)
)

with_attach = with_cavity.composeunion(attach)

Then, let’s add a hole and an opening in it.



with_opening_and_hole = (
    with_cavity
    .union(attach)
    # add a small bump to lock the cap open
    .composeunion(
        cq.Workplane("XZ", origin=(- sphere_radius - cylinder_radius - bump_depth, 0, bump_z))
        .cylinder(bump_height, bump_radius)
    )
    # dig a hole
    .composecut(
        attach_worplane.circle(hole_radius).extrude(4*sphere_radius, both=True)
    )
    # open to fix the cap on the flask
    .composecut(
        attach_worplane
        .moveTo(-hole_radius / 2, 0)
        .lineTo(hole_radius / 2, 0)
        .lineTo(top_width / 2, 10)
        .lineTo(-top_width / 2, 10)
        .close()
        .extrude(10, both=True)
    )
)

put them together

Now, I need a small part that make both the attach and the cap stick together

Because I don’t want to compute exactly the size of that piece, it may go to far in the cap, so I just need to cut the cavity to get a clean room.



put_together = (
    with_opening_and_hole
    .composeunion(
        attach_worplane
        .moveTo(hole_radius * 1.4 ,0) # approx sqrt(2) to
        .lineTo(0,-cylinder_radius)
        .lineTo(2*cylinder_radius, -2*cylinder_radius)
        .lineTo(2*cylinder_radius, 0)
        .close()
        .extrude(cylinder_height/2,both=True)
    )
    # dig the cavity again
    .composecut(cavity)
)

and then, the snap holes

There are small holes in the cap to stick with the flask and avoid opening when traveling.

I model them with small boxes that are cut in each side of the bottle.



def snap(direction=1):
    return (
        cq.Workplane("XY", origin=(0, direction * (sphere_radius - wall_width), - snap_z))
        .box(snap_width, snap_depth, snap_height)
    )

with_snap_holes = put_together.composecut(
    snap(direction=1)
    .union(snap(direction=-1))
)
