the problem

A friend has two decks of cards without a box.

  1. 65 x 100 mm, 20 mm thick
  2. 55 x 85 mm, 40 mm thick

I want a flip-top box for each, printed on the A1 mini, with the lid held closed by magnets. Same approach as new cap for a flask.

the design

The deck lies flat in an open tray (the base). A flat lid sits on top of it.

  • the hinge runs along the long back edge: knuckles alternate between the base and the lid, and a piece of 1.75 mm filament goes through them as the pin,
  • two magnets in the front wall of the base meet two magnets in the lid. The front wall gets as thick as the magnet pocket needs,
  • the lid overhangs the front by a small lip, to open it with a thumb,
  • the hinge axis sits so that, lid printed upside down, its knuckles rest on the bed: no support needed.

The magnets can be round or square: the pocket follows.

the measures

clearance = 0.5      # play around the deck, per side
wall = 2
floor = 1.6
knuckle_r = 3.5
hinge_gap = 0.4      # between knuckles, and between knuckle and box
knuckles = 5
pin_d = 1.75         # filament used as the hinge pin
pin_play = 0.35
magnet_play = 0.2
magnet_cover = 0.8   # plastic around a magnet pocket
lip = 2              # front overhang of the lid

magnet_shape = "round"  # or "square"
magnet_w = 6            # diameter, or side of the square
magnet_h = 2

the box

Base and lid are built in place, closed, the back of the base at x=0, its floor at z=0.

def card_box(deck_w, deck_l, deck_t):
    iw = deck_w + 2 * clearance
    il = deck_l + 2 * clearance
    ih = deck_t + clearance
    front = max(wall, magnet_w + magnet_play + 2 * magnet_cover)
    ow = iw + wall + front
    ol = il + 2 * wall
    oh = floor + ih
    lid_t = max(2, magnet_h + magnet_play + magnet_cover)

    base = (
        cq.Workplane("XY")
        .box(ow, ol, oh, centered=(False, True, False))
        .composecut(
            cq.Workplane("XY", origin=(wall, 0, floor))
            .box(iw, il, ih + 1, centered=(False, True, False))
        )
    )
    lid = (
        cq.Workplane("XY", origin=(0, 0, oh))
        .box(ow + lip, ol, lid_t, centered=(False, True, False))
    )

    # magnets, in the front wall and right above it in the lid
    depth = magnet_h + magnet_play
    size = magnet_w + magnet_play
    mx = wall + iw + front / 2

    def pockets(z0):
        out = None
        for y in (-ol / 4, ol / 4):
            wp = cq.Workplane("XY", origin=(mx, y, z0))
            if magnet_shape == "round":
                p = wp.circle(size / 2).extrude(depth)
            else:
                p = wp.rect(size, size).extrude(depth)
            out = p if out is None else out.union(p)
        return out

    base = base.composecut(pockets(oh - depth))
    lid = lid.composecut(pockets(oh))

    # hinge, axis along y behind the back wall, its top flush with the lid
    ax = -(knuckle_r + hinge_gap)
    az = oh + lid_t - knuckle_r
    seg = (ol - (knuckles - 1) * hinge_gap) / knuckles
    for i in range(knuckles):
        y_end = -ol / 2 + i * (seg + hinge_gap) + seg
        knuckle = (
            cq.Workplane("XZ", origin=(ax, y_end, az))
            .circle(knuckle_r).extrude(seg)
        )
        plane = cq.Workplane("XZ", origin=(0, y_end, 0))
        if i % 2 == 0:
            # 45° wedge under the knuckle, so the base prints without support
            web = (
                plane.polyline([
                    (0, oh), (ax, oh), (ax, az - knuckle_r),
                    (0, az - knuckle_r + ax),
                ]).close().extrude(seg)
            )
            base = base.composeunion(knuckle).composeunion(web)
        else:
            web = (
                plane.polyline([
                    (0, oh), (0, oh + lid_t), (ax, oh + lid_t), (ax, oh),
                ]).close().extrude(seg)
            )
            lid = lid.composeunion(knuckle).composeunion(web)

    pin = (
        cq.Workplane("XZ", origin=(ax, ol, az))
        .circle((pin_d + pin_play) / 2).extrude(2 * ol)
    )
    base = base.composecut(pin)
    lid = lid.composecut(pin)

    # the lid prints upside down, its top on the bed
    lid_print = (
        lid.rotate((0, 0, 0), (1, 0, 0), 180)
        .translate((0, 0, oh + lid_t))
    )
    return base, lid, lid_print

deck 1: 65 x 100 x 20

base1, lid1, lid1_print = card_box(65, 100, 20)


closed1 = base1.composeunion(lid1)

deck 2: 55 x 85 x 40

base2, lid2, lid2_print = card_box(55, 85, 40)


closed2 = base2.composeunion(lid2)

printing

Base floor down, lid top down, no support. Glue the magnets in, check the polarity first. Push a piece of filament through the knuckles and melt or cut its ends flush.
