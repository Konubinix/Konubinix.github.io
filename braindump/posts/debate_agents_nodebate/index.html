Debate Fragment: No-Debate (Single Writer + Audit) Orchestration

Fleeting

Defender fragment file for the adversarial debate on how a fleet of agents should orchestrate its debate. This file is OWNED by the no-debate defender — the position that rejects the premise, holding a single neutral writer plus an independent adversarial audit superior to any debate. It holds exactly one named argdown block, merged into the agents-debate-map by :argdown-include and Argdown’s merge-by-title, so the defender extends the [no-debate] node here without redefining its seed description. The cartographer leaves it empty.

// Core: debate's whole stated purpose is already met by the lone-writer audit.
<audit-already-supplies-the-guard>: The single-writer method already contains the very anti-confirmation-bias mechanism debate is introduced to add, so debate adds machinery without adding rigor.

(1) [debate-purpose]: « The debate does not REPLACE the neutral audit — it COMPLEMENTS it, guarding against the confirmation bias a lone writer slides into. » [how to run an adversarial debate](file:./how_to_run_an_adversarial_debate.org) #(acte authentique)
(2) [audit-independent]: « an independent reader — no context, no stake in the conclusion — is given the quote and the body's claim side-by-side and asked whether the claim is what the quote supports » [how to write a literature note](file:./how_to_write_a_literature_note.org) #(acte authentique)
(3) [audit-targets-conclusion]: « The instruction to the adversarial reader is not "find flaws in the presentation" but "find reasons the conclusion is wrong." » [how to write a literature note](file:./how_to_write_a_literature_note.org) #(acte authentique)
(4) [audit-iterates]: « The cycle — adversarial read, correction, adversarial read again — runs until a pass returns no objection that holds. » [how to write a literature note](file:./how_to_write_a_literature_note.org) #(acte authentique)
----
[guard-already-present]: The confirmation-bias guard that debate exists to provide is already delivered by the lone-writer method's fresh, blind, iterated adversarial audit. #(présomption)

// Debate is the exception, not the baseline — forcing it manufactures controversy.
<debate-is-escalation-only>: Debate is an escalation reserved for an already-established, genuinely-contested question; absent that, the prescribed path is a single neutral writer plus a fresh audit.

(1) [not-default]: « Debate is not the default mode. A settled or purely factual question goes the normal way (a neutral writer, a fresh audit) ... forcing a debate onto such a question manufactures a controversy where there is none. » [how to run an adversarial debate](file:./how_to_run_an_adversarial_debate.org) #(acte authentique)
(2) [fires-only-suitable]: « Debate fires when the question is SUITABLE for it: when it genuinely admits several defensible but incompatible answers » [how to run an adversarial debate](file:./how_to_run_an_adversarial_debate.org) #(acte authentique)
----
[forgo-unless-contested]: Unless a question is positively established as admitting several incompatible answers, the prescribed orchestration is a single neutral writer plus audit, and running a debate manufactures controversy. #(présomption)

// Debate's structural cost the single-writer path does not pay.
[false-balance-trap]: « The debate format's trap is false balance: giving equal weight to two theses because each was assigned a defender. » [how to run an adversarial debate](file:./how_to_run_an_adversarial_debate.org) #(acte authentique)

// On this methodological domain the debate buys little it can source.
[thin-methodological-yield]: « the domain is methodological, so many claims are reasoned rather than citable. ... An honest run may end thin, with weak tags and a documented disagreement » [how to run an adversarial debate](file:./how_to_run_an_adversarial_debate.org) #(acte authentique)

// Neutrality (a named criterion) comes from the method's design, not from opposing defenders.
[neutrality-from-method]: Neutrality is secured upstream by the neutral objective and the blind audit, not manufactured by assigning opposing defenders. #(présomption)
    + [neutrality-upstream]: « Neutrality starts upstream of the prose, in the formulation of the objective itself. ... any framing that presupposes its own answer is rewritten before the source is opened. » [how to write a literature note](file:./how_to_write_a_literature_note.org) #(acte authentique)

// Completeness (a named criterion) comes from enumeration + audit, both available without a debate.
[completeness-from-enumeration]: Completeness comes from the neutral enumeration of positions and the audit's exhaustive flaw-finding, both available without any debate among defenders. #(présomption)
    + [enumerate-first]: « enumerate the positions from the sources, neutrally, BEFORE any role is assigned ... Enumerate first, oppose second. » [how to run an adversarial debate](file:./how_to_run_an_adversarial_debate.org) #(acte authentique)
    + [audit-finds-all]: « don't report until you found ALL flaws. » [how to write a literature note](file:./how_to_write_a_literature_note.org) #(acte authentique)

<nd-atk-independence-collapses-in>: Granting independent-aggregate's own premises — that maximal blindness is best and that defenders gain nothing decision-relevant from interacting — the multi-defender apparatus is redundant: blind writers whose outputs are merely concatenated, with no inter-position adversarial pass, IS a single neutral enumeration plus audit under another name, only weaker, since no step ever asks « find reasons the conclusion is wrong » across the positions. #(présomption)

    + [enumerate-first]

<nd-atk-false-balance-by-assignment>: Assigning one defender per position — and advancing winners through a bracket — is the count-based equal footing the protocol names as the false-balance trap; weight is a property of EVIDENCE a single auditor reads straight off the sources, so staging it as a pairwise contest adds a path-dependent, self-admittedly unsourced bracket artifact (a heavy position can be paired out early) without adding any evidential information. #(présomption)
    + [false-balance-trap]
    + [nd-src-weight-not-counting]

<nd-atk-blindness-proves-too-much>: phase-parallel's core virtue — that writing blind removes anchoring — taken to its limit IS no-debate: full blindness is a single writer plus a blind audit. The attack/react phases then REINTRODUCE the very cross-influence blindness removed, behind a barrier the protocol concedes « once killed the debate »; so the blindness argument argues FOR forgoing the debate, not for staging one. #(présomption)
    + [nd-src-blind-steelman]
    + [nd-src-barrier-once-killed]

<nd-def-enumeration-and-fresh-iteration>: No-debate is not « one mind »: the positions are NEUTRALLY ENUMERATED from the sources before any writing, and the audit is ITERATED with a fresh reviewer per pass — never the same buddy twice — so several uncorrelated readers pressure the conclusion and all candidate theses are surfaced up front; that is the same uncorrelated independence the rivals claim only parallel defenders give, without the anchoring or coordination cost. #(présomption)

<nd-def-complements-is-party-claim>: The rivals lean on the protocol's « debate … COMPLEMENTS the audit » line as if it established the audit insufficient; but that is the protocol — an interested PARTY to this very debate, which the rivals themselves downgrade to « témoignage d'une partie » when it advocates their methods — asserting its own rationale, not a demonstrated constat that the audit fails. The corpus nowhere shows the iterated fresh-blind audit failing to catch framing or omission bias; « complements » states debate's PURPOSE, and no-debate's whole claim is that that purpose is already met. #(présomption)
