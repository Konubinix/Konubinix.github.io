my micro python distribution

boot.py is meant to deal with devices specific stuffs, like setting the scheduler speed.

main.py contains the application code. I want that code to follow some common patterns, like:

  • custom exception handling:
    • dump in the file system,
    • notification on my nyfy server,
  • def wifi_reset as per the doc of espnow
  • helpers to:
    • notify,
    • communicate with my other devices via espnow,
    • log,
    • deal with deep sleep,

I believe in the value of a fast feedback loop setup, so I need a way to upgrade this distribution and the main code easily, something as simple as:

  • webrepl_cli.py -p 0000 mydevice
  • C-c
  • from upgrade import upgrade
  • upgrade(“urltomy/install.json”)

install.json should look like: [ {“url”: “someurl”, “path”: “somepath”}, {“url”: “someurl”, “path”: “somepath”}, … ] The upgrade process should:

  1. read the content of the url

    requests.get(url)

  2. once processed, move it to installed.json

  3. clean the files that are in installed.json but not in install.json

  4. install the new files

  5. update the existing files only if the url changes. I will use ipfs to host the data. That means that the url contains a hash of the data and therefore simply comparing the url is enough to decide if the content is up to date or should be upgraded

  6. leave boot.py alone. That file is very board dependant

iothelper = b'\xc4[\xbeb\xc2\xdb'

class WiFi:
    def __init__(self, progress=None):
        self.wlan = network.WLAN(network.STA_IF)
        self.wasconnected = False
        self.progress = progress

    def __enter__(self):
        if self.wlan.isconnected():
            self.wasconnected = True
            print("Noop, most likely a nested call")
            return
        print("Connecting to wifi")
        self.wlan.active(True)
        self.wlan.connect()
        if self.progress:
            p = self.progress()

        while True:
            if self.wlan.isconnected():
                print("Connected to wifi")
                return self.wlan
            if self.progress:
                next(p)
            time.sleep(0.3)

    def __exit__(self, exc_type=None, exc_value=None, traceback=None):
        if isinstance(exc_value, KeyboardInterrupt):
            print("Ctrl-c => Keep wifi on for debugging")
        elif self.wasconnected:
            print("Noop, don't disturb the nested call")
            self.wasconnected = False
        else:
            print("Disconnecting from wifi")
            # return
            self.wlan.disconnect()
            self.wlan.active(False)

    def on(self):
        self.__enter__()

    def off(self):
        self.wasconnected = False
        self.__exit__()

    def reset(self):
      """Make sure the wifi is at a coherent state.

      Activating the STA and disconnecting prevent from ghost isconnected messages
      from previous run before reset.

      see https://docs.micropython.org/en/latest/library/espnow.html
      """
      sta = network.WLAN(network.WLAN.IF_STA); sta.active(False)
      ap = network.WLAN(network.WLAN.IF_AP); ap.active(False)
      sta.active(True)
      while not sta.active():
          time.sleep(0.1)
      sta.disconnect()
      while sta.isconnected():
          time.sleep(0.1)
      return sta, ap


wifi = WiFi()

def deep_sleep(msecs):
    rtc = machine.RTC()
    rtc.irq(trigger=rtc.ALARM0, wake=machine.DEEPSLEEP)
    rtc.alarm(rtc.ALARM0, msecs)
    machine.deepsleep()

def lowpower():
    machine.freq(80000000)
    if hasattr(machine, 'sleep_type'):
        machine.sleep_type(machine.SLEEP_LIGHT)
