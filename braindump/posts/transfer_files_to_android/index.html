Transfer Files to Android

Fleeting

authorship

tl;dr
unlock the device, choose « File Transfer », mount it with aft-mtp-mount, unmount it with fusermount -u.

Put the device in file transfer mode

how
the device is unlocked, then connected to the computer by USB cable1.
how
on the device, the « Charging this device via USB » notification is tapped, and « File Transfer » selected under « Use USB for »1.

Mount it

what
aft-mtp-mount is the FUSE interface of Android File Transfer for Linux, an MTP client2.
how
mkdir ~/my-device, then aft-mtp-mount ~/my-device2.
how
with nix, nix-shell -p android-file-transfer --run "aft-mtp-mount ~/my-device"3.

Unmount it

how
fusermount -u ~/my-device4.
