Des Pieds D'une Table D'enfant

Fleeting

contexte

On a :

  • des pieds qui ont la forme de pavé de section 15×80 mm suivi par un demi-cylindre de R=40 mm
  • les pieds sont inclinés ; le demi-cylindre repose sur le sol, le point de contact est à 33 mm du bord extérieur
  • épaisseur du plateau : 15 mm
  • hauteur actuelle H = 360 mm (mesurée du sol au dessus du plateau)
  • distance pied suspendu / sol : 28 mm ; angle d’inclinaison : 21°
  • objectif : porter H à 420 mm (+60 mm)

modèle d’un pied

thickness = 15   # mm, épaisseur du pavé
width     = 80   # mm, largeur du pavé
R         = 40   # mm, rayon du demi-cylindre


# longueur du pavé à déterminer (TODO : mesurer)
pave_length = 300  # mm, à ajuster

with BuildPart() as pied:
    # pavé : width (X) × thickness (Y) × pave_length (Z)
    Box(width, thickness, pave_length,
        align=(Align.CENTER, Align.CENTER, Align.MIN))
    # demi-cylindre en bas (Z<0), axe Y, profil dans XZ
    # R = width/2 : le demi-cercle couvre exactement la largeur du pavé
    with BuildSketch(Plane.XZ):
        with BuildLine():
            RadiusArc((-R, 0), (R, 0), -R)  # arc vers Z<0
            Line((R, 0), (-R, 0))             # plat à Z=0
        make_face()
    extrude(amount=thickness / 2, both=True)

manchon pour le grand pied

Le grand pied touche le sol et donne la hauteur actuelle H=360mm. Ce manchon l’allonge de 60mm verticaux pour atteindre H=420mm.

La longueur axiale du manchon = target_raise / cos(angle).

angle_deg = 21        # angle du pied / verticale (mesuré)
clearance = 0.3       # jeu d'emboîtement par côté (mm)
wall = 3.0            # épaisseur paroi du manchon (mm)
insertion_depth = 40  # profondeur d'insertion du pied (mm)
target_raise = 60     # rehausse verticale souhaitée (mm)


manchon_width = width + 2 * (wall + clearance)
manchon_thickness = thickness + 2 * (wall + clearance)
manchon_R = manchon_width / 2
extension_length = target_raise / math.cos(math.radians(angle_deg))
manchon_length = insertion_depth + extension_length

cavity_width = width + 2 * clearance
cavity_thickness = thickness + 2 * clearance
cavity_R = R + clearance

# cavité en forme de pied (boîte + demi-cylindre au fond)
with BuildPart() as cavity_part:
    Box(cavity_width, cavity_thickness, insertion_depth,
        align=(Align.CENTER, Align.CENTER, Align.MIN))
    with BuildSketch(Plane.XZ):
        with BuildLine():
            RadiusArc((-cavity_R, 0), (cavity_R, 0), -cavity_R)
            Line((cavity_R, 0), (-cavity_R, 0))
        make_face()
    extrude(amount=cavity_thickness / 2, both=True)

cavity_positioned = Pos(0, 0, manchon_length - insertion_depth) * cavity_part.part

with BuildPart() as manchon:
    # corps extérieur
    Box(manchon_width, manchon_thickness, manchon_length,
        align=(Align.CENTER, Align.CENTER, Align.MIN))
    # cavité supérieure épousant la forme du pied
    add(cavity_positioned, mode=Mode.SUBTRACT)
    # demi-cylindre en bas (Z<0)
    with BuildSketch(Plane.XZ):
        with BuildLine():
            RadiusArc((-manchon_R, 0), (manchon_R, 0), -manchon_R)
            Line((manchon_R, 0), (-manchon_R, 0))
        make_face()
    extrude(amount=manchon_thickness / 2, both=True)

manchon pour le petit pied

Le petit pied est suspendu à 28mm du sol quand le grand pied repose à plat. Son manchon doit donc compenser ces 28mm en plus des 60mm de rehausse, soit 88mm verticaux au total.

angle_deg = 21        # angle du pied / verticale (mesuré)
clearance = 0.3       # jeu d'emboîtement par côté (mm)
wall = 3.0            # épaisseur paroi du manchon (mm)
insertion_depth = 40  # profondeur d'insertion du pied (mm)
target_raise = 88     # 60mm de rehausse + 28mm pour compenser le retard
