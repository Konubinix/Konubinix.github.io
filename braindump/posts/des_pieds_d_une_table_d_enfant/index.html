contexte

On a :

  • des pieds qui ont la forme de pavé de section 15×80 mm suivi par un demi-cylindre de R=40 mm
  • les pieds sont inclinés ; le demi-cylindre repose sur le sol, le point de contact est à 33 mm du bord extérieur
  • épaisseur du plateau : 15 mm
  • hauteur actuelle H = 360 mm (mesurée du sol au dessus du plateau)
  • distance pied suspendu / sol : 28 mm ; angle d’inclinaison : 21°
  • objectif : porter H à 420 mm (+60 mm)

modèle d’un pied

thickness = 15   # mm, épaisseur du pavé
width     = 80   # mm, largeur du pavé
R         = 40   # mm, rayon du demi-cylindre


# longueur du pavé : calculée pour que le sommet touche le plateau à 420mm
# après rotation et positionnement dans le manchon
pave_length = 343  # mm

with BuildPart() as pied:
    # pavé : width (X) × thickness (Y) × pave_length (Z)
    Box(width, thickness, pave_length,
        align=(Align.CENTER, Align.CENTER, Align.MIN))
    # demi-cylindre en bas (Z<0), axe Y, profil dans XZ
    # R = width/2 : le demi-cercle couvre exactement la largeur du pavé
    with BuildSketch(Plane.XZ):
        with BuildLine():
            RadiusArc((-R, 0), (R, 0), -R)  # arc vers Z<0
            Line((R, 0), (-R, 0))             # plat à Z=0
        make_face()
    extrude(amount=thickness / 2, both=True)

manchon pour le grand pied

Le grand pied touche le sol et donne la hauteur actuelle H=360mm. Ce manchon l’allonge de 60mm verticaux pour atteindre H=420mm.

La longueur axiale du manchon = target_raise / cos(angle).

angle_deg = 21        # angle du pied / verticale (mesuré)
clearance = 0.3       # jeu d'emboîtement par côté (mm)
wall = 3.0            # épaisseur paroi du manchon (mm)
insertion_depth = 40  # profondeur d'insertion du pied (mm)
target_raise = 60     # rehausse verticale souhaitée (mm)


cavity_width = width + 2 * clearance
cavity_thickness = thickness + 2 * clearance
cavity_R = R + clearance

with BuildPart() as cavity_part:
    Box(cavity_width, cavity_thickness, insertion_depth,
        align=(Align.CENTER, Align.CENTER, Align.MIN))
    with BuildSketch(Plane.XZ):
        with BuildLine():
            RadiusArc((-cavity_R, 0), (cavity_R, 0), -cavity_R)
            Line((cavity_R, 0), (-cavity_R, 0))
        make_face()
    extrude(amount=cavity_thickness / 2, both=True)


from build123d import chamfer, fillet, Axis

manchon_width = width + 2 * (wall + clearance)
manchon_thickness = thickness + 2 * (wall + clearance)
manchon_R = manchon_width / 2
extension_length = target_raise / math.cos(math.radians(angle_deg))
manchon_length = insertion_depth + extension_length
chamfer_radius = 1.5
cylinder_chamfer = 0.8

    # corps extérieur
    Box(manchon_width, manchon_thickness, manchon_length,
        align=(Align.CENTER, Align.CENTER, Align.MIN))
    # cavité supérieure épousant la forme du pied
    add(cavity_positioned, mode=Mode.SUBTRACT)
    # demi-cylindre en bas (Z<0)
    with BuildSketch(Plane.XZ):
        with BuildLine():
            RadiusArc((-manchon_R, 0), (manchon_R, 0), -manchon_R)
            Line((manchon_R, 0), (-manchon_R, 0))
        make_face()
    extrude(amount=manchon_thickness / 2, both=True)
    # fillet unique sur arêtes extérieures : coins verticaux + bas du cylindre
    # → OCC les connecte en un fillet continu
    all_edges = manchon.part.edges()
    min_z = min(e.center().Z for e in all_edges)
    exterior_edges = [
        e for e in all_edges
        if (abs(abs(e.center().X) - manchon_width / 2) < 1
            and abs(abs(e.center().Y) - manchon_thickness / 2) < 1)
        or e.center().Z < min_z + 2
    ]
    fillet(exterior_edges, radius=chamfer_radius)

manchon pour le petit pied

Le petit pied est suspendu à 28mm du sol quand le grand pied repose à plat. Son manchon doit donc compenser ces 28mm en plus des 60mm de rehausse, soit 88mm verticaux au total.

angle_deg = 21        # angle du pied / verticale (mesuré)
clearance = 0.3       # jeu d'emboîtement par côté (mm)
wall = 3.0            # épaisseur paroi du manchon (mm)
insertion_depth = 70  # profondeur d'insertion du pied (mm, plus profond car manchon plus long)
target_raise = 88     # 60mm de rehausse + 28mm pour compenser le retard

assemblage complet

Le problème à résoudre est géométrique : placer quatre pieds dans l’espace monde de façon que la table soit de niveau, à la bonne hauteur, les cylindres posés à plat sur le sol. Trois contraintes rendent cela non trivial. D’abord les pieds sont inclinés à 21°, ce qui couple la hauteur finale et l’orientation de la pièce. Ensuite les deux côtés ne sont pas symétriques en hauteur — un côté repose sur le sol, l’autre est suspendu de 28mm — donc leurs manchons ont des longueurs différentes. Enfin il y a quatre pieds, pas deux : deux par côté, répartis sur la longueur de la table.

Les cotes ci-dessous sont provisoires et devront être vérifiées sur la vraie table.

table_width = 500     # mm, écartement centre-à-centre des pieds côté/côté (X, à mesurer)
plateau_length = 600  # mm, longueur du plateau (à mesurer)
foot_spacing = 450    # mm, écartement avant/arrière entre les deux pieds d'un même côté (Y, à mesurer)
target_height = 420   # mm, hauteur cible

Les trois variantes de rendu partagent les mêmes imports.

formes de base

Tous les pieds sont de la même forme — seules la position et l’orientation dans le monde diffèrent. On construit donc la forme une seule fois et on la clone.

Le pied modélisé s’étend théoriquement jusqu’au niveau du plateau, et même au-delà. Or la pièce physique s’arrête là où le bois commence : le pied ne traverse pas le plateau. On définit donc une grande boîte de coupe positionnée à l’aplomb du dessous du plateau et on la soustrait booléennement de chaque pied avant de l’ajouter à l’assemblage.

cutting_box_positioned = Pos(0, 0, target_height - thickness) * cutting_box

Le côté droit de la table (X+) porte les grands pieds, ceux qui reposaient déjà au sol dans la configuration d’origine. Leur manchon allonge le pied de 60mm verticaux pour atteindre la hauteur cible.

La difficulté du positionnement vient de l’inclinaison. En repère local, le bas du demi-cylindre est en Z=0. Mais après une rotation de 21°, ce point descend sous le sol. Il faut donc pré-décaler la pièce vers le haut d’une quantité lift telle que ce point revienne exactement à Z=0 après rotation. Par trigonométrie, ce décalage vaut manchon_R × cos(angle).

Dans l’assemblage, le pied est décalé de ml − id en Z local pour que son bas se retrouve exactement au fond de la cavité du manchon — la position qu’il occupera dans la pièce imprimée.

vue assemblée

Chaque côté de la table porte deux pieds identiques, l’un à l’avant, l’autre à l’arrière. On itère sur les deux décalages en Y pour les placer sans dupliquer la logique de positionnement.

La troncature doit se faire après que le pied a été mis en position dans le repère monde, parce que la boîte de coupe est axée sur Z global. Si on tronquait avant la rotation, la coupe serait de biais.

children = []
for y in [foot_spacing / 2, -foot_spacing / 2]:
    pg = Pos(table_width / 2, y, lift_g) * rot_g * pied_grand
    pg_trimmed = pg - cutting_box_positioned
    pg_trimmed.label = "grand_pied"
    pg_trimmed.color = Color("peru")
    pp = Pos(-table_width / 2, y, lift_p) * rot_p * pied_petit
    pp_trimmed = pp - cutting_box_positioned
    pp_trimmed.label = "petit_pied"
    pp_trimmed.color = Color("burlywood")
    children += [
        Pos(table_width / 2, y, lift_g) * rot_g * manchon_grand,
        pg_trimmed,
        Pos(-table_width / 2, y, lift_p) * rot_p * manchon_petit,
        pp_trimmed,
    ]

vue éclatée

Dans la vue assemblée le manchon enveloppe entièrement le pied : on ne peut pas vérifier visuellement l’alignement. La vue éclatée sert à confirmer que la cavité est correctement orientée et que le pied s’y engagera sans contrainte.

On veut écarter le manchon dans le sens où il s’enfile sur le pied — son propre axe, pas l’axe Z du monde. On applique donc le décalage en Z local avant d’appliquer la rotation monde. Ainsi le manchon s’éloigne dans la bonne direction quelle que soit l’inclinaison.

explode_offset = 80
children = []
for y in [foot_spacing / 2, -foot_spacing / 2]:
    pg = Pos(table_width / 2, y, lift_g) * rot_g * pied_grand
    pg_trimmed = pg - cutting_box_positioned
    pg_trimmed.label = "grand_pied"
    pg_trimmed.color = Color("peru")
    pp = Pos(-table_width / 2, y, lift_p) * rot_p * pied_petit
    pp_trimmed = pp - cutting_box_positioned
    pp_trimmed.label = "petit_pied"
    pp_trimmed.color = Color("burlywood")
    children += [
        Pos(table_width / 2, y, lift_g) * rot_g * Pos(0, 0, -explode_offset) * manchon_grand,
        pg_trimmed,
        Pos(-table_width / 2, y, lift_p) * rot_p * Pos(0, 0, -explode_offset) * manchon_petit,
        pp_trimmed,
    ]

vue transparente avec cavité visible

Les manchons sont rendus semi-transparents (alpha 0.3) mais le backface culling du rendu 3D supprime les faces intérieures : on ne verrait pas la cavité. Pour la rendre visible, on ajoute la forme exacte de la cavité (cavity_part) comme solide orange opaque (alpha 0.8) positionné à l’intérieur du manchon. Ainsi les arêtes de l’emboîtement sont visibles à travers le manchon transparent.

Le but de cette vue est de vérifier avant impression que les cotes d’emboîtement sont correctes : le pied doit s’engager dans la cavité sans jeu excessif ni serrage. On colore la cavité en orange, distinct du bleu du manchon, pour que les faces de contact soient lisibles malgré la transparence.

        Pos(table_width / 2, y, lift_g) * rot_g * manchon_grand,
        pg_trimmed,
        Pos(table_width / 2, y, lift_g) * rot_g * Pos(0, 0, ml_g - id_g) * cavity_grand,
        Pos(-table_width / 2, y, lift_p) * rot_p * manchon_petit,
        pp_trimmed,
        Pos(-table_width / 2, y, lift_p) * rot_p * Pos(0, 0, ml_p - id_p) * cavity_petit,
    ]

avec un manchon plat

Variante simplifiée : le manchon est un pavé rectangulaire creusé de la forme exacte du pied (boîte + demi-cylindre). Le bas n’est pas un demi-cylindre mais un plan incliné à 21° qui, une fois le manchon mis en position sur le pied, devient horizontal — le manchon pose à plat sur le sol. Pas de fillet, pas de chanfrein, pas de demi-cylindre extérieur.

Conséquence sur l’assemblage : lift = 0, car c’est le plan de coupe lui-même (au niveau de l’origine locale) qui touche le sol — pas besoin de la correction manchon_R × cos(angle) du manchon avec demi-cylindre.

La coupe angulaire se fait par soustraction d’un grand box tourné de angle_deg autour de Y, centré à −big/2 en Z local, de sorte que sa face haute coïncide exactement avec le plan incliné.

manchon_plat_width     = width + 2 * (wall + clearance)
manchon_plat_thickness = thickness + 2 * (wall + clearance)

        align=(Align.CENTER, Align.CENTER, Align.MIN))
    with BuildSketch(Plane.XZ):
        with BuildLine():
            RadiusArc((-cavity_R, 0), (cavity_R, 0), -cavity_R)
            Line((cavity_R, 0), (-cavity_R, 0))
        make_face()
    extrude(amount=cavity_thickness / 2, both=True)
cavity_plat_positioned = Pos(0, 0, manchon_plat_length - insertion_depth) * cavity_part.part

        align=(Align.CENTER, Align.CENTER, Align.MIN))
    add(cavity_plat_positioned, mode=Mode.SUBTRACT)
    with Locations(Rot(0, angle_deg, 0) * Pos(0, 0, -big / 2)):
        Box(manchon_plat_width + 20, manchon_plat_thickness + 20, big,
            mode=Mode.SUBTRACT)
