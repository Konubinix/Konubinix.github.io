CodeNames.stl

Fonctionne bien mais les cartes carrées vont sortir pendant le transport du jeu. Il faudrait faire un couvercle qui se coince dessus. On a un peu moins de 5mm de profondeur.

Couvercle press-fit

Le couvercle couvre uniquement le compartiment carré des cartes. C’est une plaque plate avec une lèvre qui descend dans l’ouverture du compartiment.

Dimensions du compartiment carré mesurées depuis le STL :

  • Trou au sommet : 70 × 70 mm
  • Rayon des coins : ~5 mm
  • Profondeur disponible : ~5 mm

Paramètres

HOLE_SIZE = 70.0            # mm, taille du trou carré (70 × 70)
HOLE_CORNER_RADIUS = 5.0    # mm, rayon des coins du trou
LID_LIP_HEIGHT = 4.0        # mm, hauteur de la lèvre (< 5mm de profondeur dispo)
LID_PLATE_THICKNESS = 1.2   # mm, épaisseur de la plaque du dessus
LID_CLEARANCE = 0.15        # mm, jeu par côté pour l'insertion
LID_PLATE_OVERHANG = 5.0    # mm, dépassement de la plaque pour la prise
LID_CHAMFER = 1.0           # mm, biseau en bas de la lèvre pour insertion progressive

Génération du couvercle

La lèvre descend dans le trou de 70 mm avec un biseau en bas pour une insertion progressive. La plaque repose sur le dessus et dépasse pour faciliter le retrait.

def make_lid():
    # Lèvre : descend dans le trou
    lip_size = HOLE_SIZE - 2 * LID_CLEARANCE
    lip_r = HOLE_CORNER_RADIUS - LID_CLEARANCE

    # Biseau : en bas de la lèvre, plus petit pour guider l'insertion
    chamfer_size = lip_size - 2 * LID_CHAMFER
    chamfer_r = max(lip_r - LID_CHAMFER, 0.1)

    # Plaque : dépasse au-delà du trou pour la prise
    plate_size = HOLE_SIZE + 2 * LID_PLATE_OVERHANG
    plate_r = HOLE_CORNER_RADIUS + LID_PLATE_OVERHANG

    with BuildPart() as lid:
        # Biseau : profil réduit en bas, s'élargit vers le haut
        with BuildSketch(Plane.XY):
            RectangleRounded(chamfer_size, chamfer_size, chamfer_r)
        with BuildSketch(Plane.XY.offset(LID_CHAMFER)):
            RectangleRounded(lip_size, lip_size, lip_r)
        loft()

        # Corps de la lèvre au-dessus du biseau
        with BuildSketch(Plane.XY.offset(LID_CHAMFER)):
            RectangleRounded(lip_size, lip_size, lip_r)
        extrude(amount=LID_LIP_HEIGHT - LID_CHAMFER)

        # Plaque du dessus
        with BuildSketch(Plane.XY.offset(LID_LIP_HEIGHT)):
            RectangleRounded(plate_size, plate_size, plate_r)
        extrude(amount=LID_PLATE_THICKNESS)

    return lid.part
