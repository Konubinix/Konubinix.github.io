Giving AI agents partial access to my running qutebrowser

why
so those agents can help me investigate issues.
what
partial means I grant seeing and interacting apart.
rule
a solution that leaves how qutebrowser is launched unchanged is preferred.
  • scope: opening its DevTools port, which needs such a change, is the fallback.
how
the agent’s tools come from a small MCP server that sends commands to the socket a running qutebrowser listens on1, with seeing and interacting in separate tools.

How the stories are tested

rule
a test runs each story, calling the tools the agent would use rather than driving a real agent.
  • scope: it reaches those tools, not the wiring of a real agent to them, which stays unmeasured.
  • how: it plays my harness too: it calls only the tools granted so far, and refuses a call to any other.
    • how: at first it grants only the tools the server marks read-only.
rule
the story’s test runs against pages served for it, rather than a real payment page or AWS page.

  • why: an AWS page needs my account and changes under the test, where a served page gives the same run each time.

  • example: a documentation page, titled « AgentCore documentation ».

    • what: like AWS’s pages, it never finishes loading: one of its images never comes.

  • example: a payment page whose total reads « Total: 42.00 € », with a « Pay » button.

rule
a dagger function runs the tests in a docker container whose image dagger builds, with qutebrowser under Xvfb.
rule
the tests are written in Python, run by pytest, and reach the tools through the MCP Python SDK.
rule
the qutebrowser a test starts has a fresh base directory, holding none of my config.
how
when qutebrowser prompts me, the test answers as I would, sending qutebrowser the command I would type, once it sees the question on the screen.

The agent interacts with that page

what
using tools separate from those that let it see it.
  • why: so my agent harness can grant the one and refuse the other.
rule
granting and refusing is the harness’s work, not these tools'.
  • why: the harness is what provides security, and I do not reinvent it.
therefore
the story passing entails the server marks no click tool read-only, since the harness, granting only the tools so marked, refuses the click and « Pay » stays unclicked.

a tool marked read-only that still acts on the page would pass unseen.
therefore

The server

what
that server is a module, mcp_qutebrowser, which my own MCP server mounts beside its other themes.
how
it finds that socket where qutebrowser puts it: under my runtime directory, named after my user2.
  • how: when nothing listens there, every tool says qutebrowser is not running.

def runtime():
    return pathlib.Path(os.environ.get("XDG_RUNTIME_DIR", f"/run/user/{os.getuid()}")) / "qutebrowser"


def send(command):
    name = hashlib.md5(getpass.getuser().encode()).hexdigest()
    path = runtime() / f"ipc-{name}"
    with socket.socket(socket.AF_UNIX) as ipc:
        try:
            ipc.connect(str(path))
        except (FileNotFoundError, ConnectionRefusedError):
            raise RuntimeError(f"qutebrowser is not running: nothing listens on {path}") from None
        ipc.sendall((json.dumps({"args": [command], "target_arg": None, "protocol_version": 1}) + "\n").encode())
how
to see the page, it has qutebrowser hand the page to a small script, which copies it where the server reads it back, looking every tenth of a second and giving up after ten.
how
given a CSS selector, it returns only the elements that match, so a big page can be read in parts.
  • how: asked for text, it returns only their text, one element to a line, so a list drowned in markup reads as its names.
how
since the HTML of a field holds what it first held, not what it holds now, the page first writes each field’s live value into its HTML, marking itself as an interaction does.
  • scope: this leaves each field holding what it held, so I see no change, though the page’s scripts could.
how
it marks the tools that see as read-only, so a harness can grant them by that mark alone.

HAND_OVER_WAIT = 10  # seconds
HAND_OVER_POLL = 0.1  # seconds


def wait_for(path, whole=lambda data: True, wait=HAND_OVER_WAIT):
    deadline = time.monotonic() + wait
    while not (path.exists() and whole(path.read_bytes())):
        if time.monotonic() > deadline:
            raise TimeoutError(f"qutebrowser never handed {path.name} over")
        time.sleep(HAND_OVER_POLL)


def page_html(wait=HAND_OVER_WAIT):
    with tempfile.TemporaryDirectory() as tmp:
        dom, script = pathlib.Path(tmp) / "dom.html", pathlib.Path(tmp) / "hand-over"
        script.write_text('#!/bin/sh\ncp "$QUTE_HTML" "$1.part" && mv "$1.part" "$1"\n')
        script.chmod(0o755)
        send(f":spawn --userscript {script} {dom}")
        wait_for(dom, wait=wait)
        return dom.read_text()


LIVE_VALUES = (
    "document.querySelectorAll('input, textarea').forEach(field =>"
    " ['checkbox', 'radio'].includes(field.type) ? field.toggleAttribute('checked', field.checked)"
    " : field.localName == 'textarea' ? field.textContent = field.value"
    " : field.setAttribute('value', field.value))"
)


@qutebrowserserver.tool(annotations=ToolAnnotations(readOnlyHint=True))
def readonly_read_dom(selector: str = "", text: bool = False) -> str:
    """The DOM of the page qutebrowser shows, as HTML, its fields holding their live values, or only the elements SELECTOR picks.

    With TEXT, only the text of each element, one to a line, without its markup."""
    page = bs4.BeautifulSoup(act(LIVE_VALUES), "html.parser")
    elements = page.select(selector) if selector else [page]
    if text:
        return "\n".join(element.get_text(" ", strip=True) for element in elements)
    return "\n".join(str(element) for element in elements)
how
to show the page as I see it, it has qutebrowser save a screenshot, and reads the image back the same way, once the file ends with the chunk that closes every PNG, since qutebrowser writes it in place.

PNG_END = b"IEND\xaeB`\x82"


@qutebrowserserver.tool(annotations=ToolAnnotations(readOnlyHint=True))
def readonly_screenshot() -> Image:
    """What qutebrowser shows of the page, as a PNG."""
    with tempfile.TemporaryDirectory() as tmp:
        shot = pathlib.Path(tmp) / "shot.png"
        send(f":screenshot {shot}")
        wait_for(shot, lambda data: data.endswith(PNG_END))
        return Image(data=shot.read_bytes(), format="png")
what
qutebrowser’s socket answers nothing3, so the server cannot tell when a command has taken effect.
how
so to interact, it has the page run a small script, setting the value of the field a selector picks, then mark itself, and reads the page back until the mark shows, giving up once the ten seconds it grants a hand-over have gone by without it.
  • how: a click, qutebrowser makes, as a mouse would, then the page marks itself.
    • why: some menus open as the mouse is pressed, which no click by script does.
    • how: first, the page checks an element matches and is shown, since qutebrowser tells the server nothing when it cannot click.
  • scope: the mark stays in the page as an attribute.
  • how: when the script fails, the page marks itself all the same, adding why, and the agent is told that why.
  • how: before a click or a fill, the element is scrolled into view and framed for a second, so I follow.
    • how: the frame is the tool’s own, laid above the page over the element’s box, so no style of the page hides it, and it goes once the action is done.
  • how: a fill sets the value the way a framework expects, then tells the field it heard an input.
  • how: each action has a twin, confirm_click, confirm_fill and confirm_upload, with which the page asks me, just under the framed element, whether the agent may act, and the agent is told when I refuse.
    • how: I answer yes or no to qutebrowser’s own prompt, which a script of the page cannot answer for me.
      • how: the page is let to draw the question before the prompt stops it.
    • how: the question names no selector, the frame showing me the element already.
    • why: my harness grants the one or the other, so I choose, tool by tool, what the agent does unasked.
    • how: the twins wait two minutes for my answer, not the ten seconds a hand-over takes.
    • how: they ask at once, with no second of framing first, since the question already waits for me.

ANSWER_WAIT = 120  # seconds I have to answer


def act(script, wait=HAND_OVER_WAIT):
    mark = uuid.uuid4().hex
    send(
        f":jseval --quiet (async () => {{ let failure = ''; try {{ {script} }} catch (error) {{ failure = ' ' + error.message }}"
        f" document.documentElement.dataset.qutebrowserMcp = '{mark}' + failure }})()"
    )
    deadline = time.monotonic() + wait
    while not (done := re.search(f'data-qutebrowser-mcp="{mark}([^"]*)"', page := page_html(wait))):
        if time.monotonic() > deadline:
            raise TimeoutError("the page never showed the action done")
    if done[1]:
        raise RuntimeError(html.unescape(done[1].strip()))
    return page


HIGHLIGHT = 1000  # milliseconds


ASKED = (
    " const asked = async question => {"
    " const panel = document.createElement('div');"
    " panel.style.cssText = 'position: fixed; z-index: 2147483647; background: #800080; color: white;"
    " font: 14px sans-serif; padding: 6px; left: ' + box.left + 'px; top: ' + (box.bottom + 6) + 'px';"
    " panel.textContent = question;"
    " document.documentElement.appendChild(panel);"
    " try {"
    " await new Promise(requestAnimationFrame); await new Promise(requestAnimationFrame);"
    " return confirm('Yes or no?') } finally { panel.remove() } };"
)


def highlighted(selector, action, doing, ask):
    question = json.dumps(f"May the agent {doing}?")
    refusal = json.dumps(f"you refused to let the agent {doing}, at {selector}")
    return (
        f"const element = document.querySelector({json.dumps(selector)});"
        " element.scrollIntoView({block: 'center'});"
        " const box = element.getBoundingClientRect();"
        " const frame = document.createElement('div');"
        " frame.style.cssText = 'position: fixed; z-index: 2147483647; pointer-events: none;"
        " border: 3px solid #ff00ff; left: ' + (box.left - 3) + 'px; top: ' + (box.top - 3) + 'px;"
        " width: ' + box.width + 'px; height: ' + box.height + 'px';"
        " document.documentElement.appendChild(frame);"
        + (ASKED if ask else "")
        + " try {"
        + (f" if (!await asked({question})) throw new Error({refusal});" if ask
           else f" await new Promise(resolve => setTimeout(resolve, {HIGHLIGHT}));")
        + f" {action};"
        " } finally { frame.remove() }"
    )


def answered(ask):
    return ANSWER_WAIT if ask else HAND_OVER_WAIT


def clicking(selector, ask):
    act(
        f"const element = document.querySelector({json.dumps(selector)});"
        f" if (!element) throw new Error({json.dumps(f'no element matches {selector}')});"
        f" if (!element.getClientRects().length) throw new Error({json.dumps(f'{selector} is not shown, so no mouse reaches it')})"
    )
    act(highlighted(selector, "", "click here", ask), answered(ask))
    send(f":click-element --select-first css {shlex.quote(selector)}")
    act("")
    return f"clicked {selector}"


@qutebrowserserver.tool()
def click(selector: str) -> str:
    """Click the element SELECTOR picks, once it stood out for a second."""
    return clicking(selector, ask=False)


@qutebrowserserver.tool()
def confirm_click(selector: str) -> str:
    """Click the element SELECTOR picks, once it stood out and I accepted the click in qutebrowser."""
    return clicking(selector, ask=True)


def filling(selector, text, ask):
    act(highlighted(
        selector,
        f"Object.getOwnPropertyDescriptor(Object.getPrototypeOf(element), 'value').set.call(element, {json.dumps(text)});"
        " element.dispatchEvent(new Event('input', {bubbles: true}))",
        f"fill this with « {text} »",
        ask,
    ), answered(ask))
    return f"filled {selector}"


@qutebrowserserver.tool()
def fill(selector: str, text: str) -> str:
    """Put TEXT in the field SELECTOR picks, in place of what it held, once it stood out for a second."""
    return filling(selector, text, ask=False)


@qutebrowserserver.tool()
def confirm_fill(selector: str, text: str) -> str:
    """Put TEXT in the field SELECTOR picks, once it stood out and I accepted the fill in qutebrowser."""
    return filling(selector, text, ask=True)
what
no page script can choose the file of a file input, and the chooser qutebrowser opens is beyond the agent.
how
so to upload, qutebrowser is told, for this session only, to take its chooser’s answer from a command printing the path, then the input is activated, and the settings go back to theirs once a file input of the page holds a file it did not hold before.
  • why: on AWS, the input took the file while no change reached the document.
  • how: the page focuses the element, and qutebrowser presses space on it, as I would.
    • why: the page opens no chooser for a click by script.
    • why: a click by qutebrowser opened no chooser on the visually hidden input of an AWS form, and a key goes to the focused element, wherever its box.

CHOOSERS = ["fileselect.single_file.command", "fileselect.multiple_files.command"]
CHOSEN_WAIT = 5  # seconds, within the hand-over's ten


def uploading(selector, path, ask):
    send(":set --temp fileselect.handler external")
    for chooser in CHOOSERS:
        send(f":set --temp {chooser} {shlex.quote(json.dumps(['echo', path]))}")
    try:
        act(highlighted(
            selector,
            "window.qutebrowserMcpBefore = new Map([...document.querySelectorAll('input[type=file]')].map(input => [input, input.value]));"
            " element.focus()",
            f"upload {path} here",
            ask,
        ), answered(ask))
        send(":fake-key <Space>")
        act(
            "const chosen = () => [...document.querySelectorAll('input[type=file]')]"
            ".some(input => input.value && input.value != window.qutebrowserMcpBefore.get(input));"
            f" const deadline = Date.now() + {CHOSEN_WAIT * 1000};"
            f" while (!chosen() && Date.now() < deadline) await new Promise(resolve => setTimeout(resolve, {HAND_OVER_POLL * 1000}));"
            " if (!chosen()) throw new Error("
            f"{json.dumps(f'qutebrowser pressed space on {selector}, yet no file input took a file within {CHOSEN_WAIT} seconds:')}"
            " + ' name the file input, or the element that opens its chooser')"
        )
    finally:
        for setting in ["fileselect.handler", *CHOOSERS]:
            send(f":config-unset --temp {setting}")
    return f"uploaded {path} into {selector}"

how
to open a link, it marks the page it leaves, has qutebrowser open the link, in the tab I see or in a new one made current, and waits for a page without that mark to have loaded.
  • how: the link goes to qutebrowser as it is, since :open takes the rest of its line whole: quoted, it read as words to search.

def opening(url, command):
    left = uuid.uuid4().hex
    act(f"document.documentElement.dataset.qutebrowserMcpLeft = '{left}'")
    send(f"{command} {url}")
    deadline = time.monotonic() + HAND_OVER_WAIT
    while True:
        try:
            act(
                f"if (document.documentElement.dataset.qutebrowserMcpLeft == '{left}'"
                " || document.readyState != 'complete') throw new Error('still loading')"
            )
            return f"opened {url}"
        except (RuntimeError, TimeoutError):
            if time.monotonic() > deadline:
                raise TimeoutError(f"{url} never finished loading") from None
            time.sleep(HAND_OVER_POLL)


@qutebrowserserver.tool()
def open_url(url: str) -> str:
    """Open URL in the tab qutebrowser shows, once it loaded."""
    return opening(url, ":open")


@qutebrowserserver.tool()
def open_url_in_new_tab(url: str) -> str:
    """Open URL in a new tab, made the one qutebrowser shows, once it loaded."""
    return opening(url, ":open --tab")
