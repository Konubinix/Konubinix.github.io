Tezos API Gateway

Fleeting

  • External reference: https://gitlab.com/xdev-tech/xdev-enterprise-business-network/tezos-api-gateway/

An open source blockchain gateway to discuss with tezos blockchain nodes.

It provides the classical forge, sign, inject workflow and can rely on some user custody to perform the whole flow automatically, letting the custody dealing with the blockchain accounts keys.

It is also able to request a pool of tezos blockchain indexers to check the operations status.

It is mostly based on communicating with smart-contracts so far.

It provides a way of requesting smart-contract storage, even the bigmap, using an ad-hoc object traversal language.
