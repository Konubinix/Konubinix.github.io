Multi-Token

Fleeting

A multi-token smart-contract handles several tokens instead of only one.

An account then has several balances, each one associated to the token.

In a sense, this is an implementation of semi-fungibility, where each token indistinguishable (then not fungible) but in each token the values are fungible.
