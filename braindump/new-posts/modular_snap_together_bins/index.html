Modular Snap Together Bins

Fleeting

tag: learning 3D printing

Looking for free, open-source modular 3D printable bins that snap together side-by-side, like MultiBin from MultiBuild but free. Gridfinity requires a baseplate which is not suitable here.

Inspired by Jujumo’s interlocking and stackable containers V3, we designed a parametric system in build123d with Claude.

The parameters are calibrated to fit well with a 0.8mm nozzle on a bambulab a1 mini.

Vase mode printing

The bins are designed for vase mode (aka spiral/contour mode). In vase mode, the slicer prints a single continuous spiral — no retractions, no seams. The model must therefore be a solid block: the slicer itself creates the thin wall by tracing the outer contour. This means we extrude a solid shape and let the slicer hollow it out, rather than modeling walls explicitly.

This constrains the geometry: everything must be a single continuous shell with no internal features, overhangs that would need support, or disconnected volumes.

Snap-fit interlocking

The bins interlock by sliding together vertically. Each bin has male sides (front, left) with protruding dovetail fingers and female sides (back, right) with matching notches. When two bins are placed side by side, the male fingers of one slide into the female notches of its neighbor.

To make them actually snap rather than just slide, each male dovetail has a barb — a ridge that bulges wider than the notch entry at 70% of the depth. The thin vase-mode walls flex slightly as the barb passes through, then spring back to lock behind it. This creates a satisfying click and holds the bins together without glue.

Parameters

The design is fully parametric. Grid unit controls the base size, finger ratio controls how much of each grid cell is occupied by a finger, and the snap parameters control how tight the fit is.

GRID_UNIT = 15.0        # mm per grid unit
BUMPS_PER_UNIT = 1      # number of dovetail fingers per grid unit
FINGER_RATIO = 0.2      # fraction of sub-cell used for finger width (rest is flat margin)
FINGER_DEPTH = 5      # mm, how far bumps protrude / notches recede
DOVETAIL_TAPER = 1    # mm, extra width per side at the tip (subtle taper)
SNAP_BARB = 0.35        # mm, extra width of snap ridge beyond dovetail taper
SNAP_POS = 0.7          # 0-1, position of snap ridge along depth (0=base, 1=tip)
CLEARANCE = 0.3        # mm, fit clearance between fingers (more room for barb passage)
FINGER_LEFT_RATIO = 0.15  # 0-0.5, how far left of center to shift each finger (0=centered, 0.5=left edge)

Grid-aligned fingers

Each wall gets BUMPS_PER_UNIT fingers per GRID_UNIT of length. Each finger is centered in its sub-cell of width GRID_UNIT / BUMPS_PER_UNIT. The finger width is sub * FINGER_RATIO, leaving flat margins on each side. This grid alignment guarantees that bins of any size snap together: a 1×1 bin’s fingers align with the corresponding region of a 3×2 bin’s wall, because every finger sits at the same absolute grid position.

Dovetail profile with snap barb

The dovetail is a 2D trapezoidal profile extruded to full height. The base sits flush with the wall; the tip protrudes outward and is wider than the base (the “dovetail” shape prevents pullout).

When barb > 0, the profile gains two extra points creating a bulge at SNAP_POS along the depth. This bulge is wider than even the tip, creating the interference that makes it snap.

The profile is parameterized by direction (-x, +x, -y, +y) so the same function works for all four walls.

def _make_dovetail(base_w, tip_w, depth, height, direction, barb=0.0):
    hb = base_w / 2
    ht = tip_w / 2
    barb_d = depth * SNAP_POS
    hbarb = ht + barb / 2
    if direction == "-y":
        if barb > 0:
            pts = [(-hb, 0), (-hbarb, -barb_d), (-ht, -depth), (ht, -depth), (hbarb, -barb_d), (hb, 0)]
        else:
            pts = [(-hb, 0), (-ht, -depth), (ht, -depth), (hb, 0)]
    elif direction == "+y":
        if barb > 0:
            pts = [(-hb, 0), (-hbarb, barb_d), (-ht, depth), (ht, depth), (hbarb, barb_d), (hb, 0)]
        else:
            pts = [(-hb, 0), (-ht, depth), (ht, depth), (hb, 0)]
    elif direction == "-x":
        if barb > 0:
            pts = [(0, -hb), (-barb_d, -hbarb), (-depth, -ht), (-depth, ht), (-barb_d, hbarb), (0, hb)]
        else:
            pts = [(0, -hb), (-depth, -ht), (-depth, ht), (0, hb)]
    elif direction == "+x":
        if barb > 0:
            pts = [(0, -hb), (barb_d, -hbarb), (depth, -ht), (depth, ht), (barb_d, hbarb), (0, hb)]
        else:
            pts = [(0, -hb), (depth, -ht), (depth, ht), (0, hb)]
    with BuildSketch() as sk:
        with BuildLine():
            Polyline(*pts, close=True)
        make_face()
    return extrude(sk.sketch, height)

Assembling the bin

The bin starts as a solid box (remember: vase mode hollows it). Then we add male dovetail bumps with snap barbs on the front (-y) and left (-x) walls, and cut female notches on the back (+y) and right (+x) walls. The notches are slightly wider to accommodate the barb passage plus clearance.

Each wall gets BUMPS_PER_UNIT fingers per GRID_UNIT, evenly spaced. Because every bin uses the same grid, fingers always align regardless of bin size.

def make_bin(width_units=1, depth_units=1, height=50.0):
    ow = width_units * GRID_UNIT
    od = depth_units * GRID_UNIT
    sub = GRID_UNIT / BUMPS_PER_UNIT  # sub-cell size
    fw = sub * FINGER_RATIO
    fd = FINGER_DEPTH
    dt = DOVETAIL_TAPER
    cl = CLEARANCE
    bin_solid = Box(ow, od, height, align=(Align.CENTER, Align.CENTER, Align.MIN))

    n_front = width_units * BUMPS_PER_UNIT
    n_side = depth_units * BUMPS_PER_UNIT

    # Offset bumps slightly toward the start of each sub-cell
    bump_offset = sub * FINGER_LEFT_RATIO

    # Front wall: male bumps with snap barbs
    for k in range(n_front):
        x = -ow / 2 + sub * (k + 0.5) - bump_offset
        bump = _make_dovetail(fw, fw + 2 * dt, fd, height, "-y", barb=SNAP_BARB)
        bin_solid = bin_solid + Pos(x, -od / 2, 0) * bump

    # Back wall: female notches
    for k in range(n_front):
        x = -ow / 2 + sub * (k + 0.5) - bump_offset
        notch = _make_dovetail(fw + 2 * cl, fw + 2 * dt + 2 * cl + SNAP_BARB, fd, height, "-y")
        bin_solid = bin_solid - Pos(x, od / 2, 0) * notch

    # Left wall: male bumps with snap barbs
    for k in range(n_side):
        y = -od / 2 + sub * (k + 0.5) - bump_offset
        bump = _make_dovetail(fw, fw + 2 * dt, fd, height, "-x", barb=SNAP_BARB)
        bin_solid = bin_solid + Pos(-ow / 2, y, 0) * bump

    # Right wall: female notches
    for k in range(n_side):
        y = -od / 2 + sub * (k + 0.5) - bump_offset
        notch = _make_dovetail(fw + 2 * cl, fw + 2 * dt + 2 * cl + SNAP_BARB, fd, height, "-x")
        bin_solid = bin_solid - Pos(ow / 2, y, 0) * notch

    if isinstance(bin_solid, _b123d.topology.shape_core.ShapeList):
        return max(bin_solid, key=lambda s: s.volume)
    return bin_solid
